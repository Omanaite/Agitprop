# Proposal: Admin Content Management

## Intent
Enable the artist/administrator to authenticate and manage public content (gallery and posts) through a private admin experience.

## Scope
- Admin authentication and role-based access.
- Admin console entry point.
- CRUD for gallery items.
- CRUD for posts/publications.
- Extensibility guidelines for future content types.

## Out of Scope
- Public redesign.
- Advanced analytics.
- Multi-tenant roles.

## Affected Areas
- auth
- admin-console
- gallery-management
- posts-management
- extensibility
